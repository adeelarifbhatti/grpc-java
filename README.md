# gRPC java Server Maven Project "Key Value"

It uses openjdk-8-jdk, eclipse along with maven should be available on the machine.

###### Client

With the client we can enter the key-value in the Hashmap, the client used is the bloomrpc, the proto file needs to be added and the right localhost:9090 needs to be entered in order for it to work.

###### Server

Import the project in the eclipse as a maven project, right click on the project and click on the run as/maven install. Afterwards right click on the project again click on run as/java project
